## ✦ About the Project

AcousticX is a single-page product landing page designed to present premium wireless headphones through a clean layout, bold typography, and a modern visual style. It was created as hands-on practice during my journey into front-end and full-stack development.

## ✦ Features

- **Product-focused hero section** with a clear visual hierarchy
- **Responsive layout** using CSS Flexbox and media queries
- **Modern typography** and a minimalist design
- **Hover transitions** for interactive elements
- **Mobile-friendly styling** designed to avoid horizontal overflow

## ✦ Built With

- HTML5
- CSS3
- Flexbox
- Media Queries

## ✦ What I Practised

- Structuring a page with semantic HTML
- Styling layouts and spacing with CSS
- Making a page adapt to different screen sizes
- Refining visual presentation through independent practice
